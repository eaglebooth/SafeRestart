# SafeRestart visual direction

Source asset: user-provided green equipment restart mark.

## Extracted language

- Mood: clean industrial safety console; calm, controlled and operational.
- Primary emerald: `#38d487`; deep machine green: `#064f42`.
- Safety mint: `#dff8eb`; warm work-surface: `#f5f2e8`; ink: `#10251f`.
- Shape vocabulary: large mechanical arcs, rounded-square housings, circular power control.
- Contrast: dark instrument panels against pale mint/ivory work surfaces.

## UI system

- Display type: Barlow Condensed, uppercase instrumentation labels.
- Body type: Manrope, compact readable controls.
- 12-column desktop console with asymmetric status rail; single-column mobile fallback.
- Corners: 18px panels, 12px controls, full-circle status lamps.
- Borders: dark 1px technical rules; no glassmorphism.
- Motion: status lamp pulse and 350ms panel reveal only.

## Distinctive composition

The interface resembles an equipment restart permit clipped to a physical control cabinet. A vertical lifecycle rail replaces conventional dashboard cards; transaction activity is shown as an instrument strip.
